# 2026-08-24 Prometheus 监控指标（feat-metrics）

## 概述

新增 `GET /metrics` 端点（与 `/health` 同级，无需 JWT），输出 Prometheus 文本格式指标（前缀 `juanniang_`），覆盖消息事件流、Agent 循环、LLM 用量、群管理、插件、外部服务健康与 HTTP API 八组指标 + Go runtime/process 自带指标。

## 架构

- **库**：`github.com/prometheus/client_golang`（独立 registry，含 GoCollector + ProcessCollector）
- **代码**：`internal/metrics`（指标定义 / runtimeCollector / TTL 缓存 / Hertz 中间件）
- **采集分层**：
  - Counter/Histogram 在事件发生点原子埋点（热路径 <1μs）
  - Gauge 由 `runtimeCollector` 在 scrape 时从注入回调实时读取（`main.go` 装配 `SetRuntimeProviders`）
  - DB 类数据用 `CachedInt/CachedMap` TTL 缓存（60s），scrape 不打库
  - 外部服务健康 15s TTL 并行探测（未配置的服务不输出，避免误报）

## 指标清单

| 组 | 指标 | 说明 |
|----|------|------|
| 消息流 | `juanniang_events_total{post_type}` / `juanniang_messages_total{message_type}` / `juanniang_message_dedup_dropped_total` / `juanniang_message_blocked_total{reason}` / `juanniang_message_dropped_total{reason=irrelevant/silenced/flood}` | 吞吐与丢弃分型 |
| Agent | `juanniang_agent_loops_total{outcome=ok/error/timeout}` / `_active` / `_duration_seconds` | 循环结果/活跃/耗时（1s~5min 桶） |
| 并发 | `juanniang_agent_concurrency_in_use` / `_waits_total{result}` / `_wait_seconds` | 全局槽占用与等待 |
| LLM | `juanniang_llm_requests_total{provider,result}` / `_tokens_total{phase=agent/review/relevance}` / `_latency_seconds` | 调用/成本/延迟 |
| 群管理 | `juanniang_groupmgr_violations_total{category,action}` / `_detections_total{path,verdict}` / `_rag_score` / `_llm_reviews_total{result}` / `_spam_total{type}` | 处罚/判定流水/RAG 分数分布/审核/刷屏 |
| RAG | `juanniang_rag_search_latency_seconds` / `_errors_total` | 检索延迟与降级 |
| 插件 | `juanniang_plugins_loaded` / `juanniang_plugin_hook_errors_total{plugin,hook}` / `_duration_seconds` | 插件规模/错误定位/钩子耗时 |
| HTTP | `juanniang_http_requests_total{method,path,status}` / `_request_duration_seconds` | 路由模板化 path |
| 库存 | `juanniang_inventory{resource}` | knowledge_items/memory_items/chat_areas/sessions/cron_jobs/scheduled_messages/providers_active/mcp_servers |
| 健康 | `juanniang_external_health{service=rag/t2i/sandbox/redis}` | 0/1 矩阵 |

## 设计约束

- 标签仅低基数（无 group_id/user_id/provider 全名）；按群分析用 Web 统计面板
- 不依赖 Redis（Redis 挂了 metrics 照常 scrape）
- `/metrics` 无鉴权；公网暴露需部署层限源 IP
